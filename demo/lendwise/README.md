# Lendwise

Lendwise is a modern consumer lending platform built for non-bank financial
institutions. It provides end-to-end loan origination, servicing, and analytics
through a RESTful API backed by FastAPI and SQLAlchemy. Lendwise is designed for
operational teams that need fast onboarding, flexible underwriting rules, and
reliable audit trails across the full loan lifecycle.

The platform supports multi-channel access including web, mobile, and internal
operations tooling. A separate legacy support interface allows ops staff to assist
customers without disrupting the primary API surface. Nightly data exports feed
downstream analytics and underwriting scoring pipelines, enabling data-driven
decisions on loan approvals and portfolio management.
