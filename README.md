# Amend

> Regulatory redlines in. Verified pull requests out.

Amend is an AI-powered engine that reads regulatory change documents, diffs them against your existing policy and code, and produces a pull request with the minimum changes needed to bring the system into conformance. It runs as an IBM Bob agent, using a structured set of tools to parse rules, trace obligations through your codebase, and emit conventional commits. All generated code is validated against a synthetic test suite before the pull request is opened, so every suggested change arrives already green.
